# Decision records

One file per architectural choice, numbered in order: `NNNN-short-slug.md`. Short is the
point; if it needs more than a page, the decision isn't settled.

## Template

```markdown
# NNNN — Title

**Status:** proposed | accepted | superseded by NNNN
**Date:** YYYY-MM-DD

## Decision

One paragraph: what we chose.

## Why, and what threat it addresses

One paragraph: the reason, tied back to a row of the threat model where possible.

## Alternatives considered

Bullet list, one line each, with the reason it lost.

## Consequences

What this makes easier, what it makes harder, what must now stay true.
```
