# Research

Notes from reading and from practitioner conversations, gathered in Phase 0. One file per
source or conversation. Anonymize people and organizations unless they explicitly agreed to be
named.

## Practitioner guide summaries

Each note distills a canonical practitioner-facing security guide into takeaways for a
membership/contact ledger specifically — not general security advice. Each is tagged with
`[feature]` / `[avoid]` where the source implies something Cadre should or shouldn't do, and
notes any explicit threat-model vocabulary the source uses that `docs/threat-model.md` can
draw on.

- [EFF Surveillance Self-Defense](eff-surveillance-self-defense.md) — individual-focused risk
  assessment framework (assets/adversaries/capabilities); metadata-is-sensitive framing.
- [Tactical Tech, Holistic Security](tactical-tech-holistic-security.md) — four-phase
  Prepare/Explore/Strategise/Act cycle; capacities/threats/vulnerabilities vocabulary within it;
  organizational security and offboarding practices.
- [Freedom of the Press Foundation training](freedom-of-the-press-foundation.md) — source
  protection as the closest analogue to a member/contact list; legal compulsion as a first-class
  adversary.
- [Access Now Digital Security Helpline](access-now-digital-security-helpline.md) — incident
  response framing (what to do once compromise has happened); real-world incident mix for
  under-resourced organizations.

Written on 2026-09-17 without outbound network access, then spot-checked against the live
pages the same day. EFF's and Freedom of the Press Foundation's notes held up as written;
Access Now's and Tactical Tech's had corrections made — see each file's footer for what
changed.
